# Application Development Labs

A collection of small applications developed to explore programming languages, application architectures, and software development fundamentals.

## Projects

### [Call Target Calculator](./call-target-calculator)

A call target calculator implemented across three different platforms:

- Java (Console)
- C# (WinForms)
- JavaScript (Web)

### [Password Strength Checker](./password-strength-checker)

A password strength evaluation application implemented across three different environments:

- Java (Console)
- JavaFX (GUI)
- Node.js (CLI)
